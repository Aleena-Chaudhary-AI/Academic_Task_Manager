# Academic Task Manager 

A beautiful, responsive web application for managing academic tasks, exams, assignments, and study goals.

## Features 

- Add and manage academic tasks (exams, vivas, assignments, projects)
- Auto-save to browser local storage
- Track study hours and progress
- Set study goals with visual progress bars
- Due date tracking with smart notifications
- Export/Import your data
- Fully responsive design
- Beautiful gradient UI with animations

## How to Use 

1. Open `index.html` in your web browser
2. Add your academic tasks with details
3. Track your study progress
4. Your data automatically saves to your browser

## Technologies Used 

- HTML5
- CSS3 (Tailwind CSS)
- JavaScript (ES6+)
- Local Storage API
